# Cómo colaborar

¡Gracias por el interés! Unas pautas rápidas:

1. **Propón preguntas** abriendo una issue o editando `worker/src/questions/banco.json`. Deben responderse con sí o no, valer para cualquier persona en España y evitar partidos, religión, personas reales y temas que hieran a alguien.
2. **Para cambios de código**, crea una rama, ejecuta `npm run check` (lint, tests y compilación) y abre una pull request explicando el porqué.
3. Mantén el tono del proyecto: textos en español, con el registro del boletín («usted»).
